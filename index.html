쓰던 기기의 FS 포털과 연결

쓰던 기기에서 만든 6자리 코드를 넣으면 관리자 승인 없이 바로 열립니다.

  1. 쓰던 기기(PC·휴대폰)에서 FS 포털을 엽니다
  2. 메뉴 → 설정 → 「다른 기기 연결」을 누릅니다
  3. 화면에 나온 6자리 숫자를 위 칸에 넣고 「연결」

승인을 기다리고 있어요

등록 요청을 보냈습니다. 관리자가 승인하면 이 화면이 자동으로 바뀝니다.

  1. 이름 선택
  2. 관리자 승인
  3. 사용 시작
승인은 FSS팀(관리자)이 합니다. 급하면 팀장이나 FSS팀에 「FS 포털 승인 부탁」이라고 알려 주세요. 이 화면은 닫아도 되고, 다시 열면 이어집니다.
